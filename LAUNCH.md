# Чек-лист: демо → сдача → запуск

Общий чек-лист запуска — `D:\IT\IT Projects\CLAUDE\websites\launch-checklist.md`; здесь он же плюс то, что даёт шаблон.
Отметки ставить в копии этого файла в репозитории клиента.

## 1. Демо — до первой ссылки клиенту
- [ ] `npm run apply-client` без ошибок; отчёт «Можно улучшить» прочитан, решено, что оставить.
- [ ] `npm run build` → `visual-check`: главная, одна услуга, главная второго языка × 4 ширины — без переполнения и ошибок JS.
- [ ] Вверху баннер «Demoversie…» (`demo: true`).
- [ ] Превью не индексируется: `curl -I https://<проект>.vercel.app` → `X-Robots-Tag: noindex`.
- [ ] **Форма доставляет на этом проекте**: переменные из `.env.example` заданы в Vercel, тестовая заявка пришла (письмо и/или Telegram), «Спасибо» показано только после доставки. Тестовую заявку удалить.
- [ ] Открыто на настоящем телефоне (эмуляция ширины ≠ устройство).
- [ ] Чужих фактов нет: всё из `sources`, ничего не выдумано, фото — клиента или с его сайта/профиля (в `sources`).

## 2. Сдача — факты подтверждены клиентом
- [ ] Анкета `CLAUDE/sjablonen/client-facts-checklist.md` пройдена, ответы с датой — в `CLAUDE.md` проекта.
- [ ] В `client.json`: `demo: false`; `sources` — «клиент, <дата>».
- [ ] `legalName`, `vat` (BTW/KBO обязателен в BE), `email`, адрес и `showAddress`, часы = Google Бизнес-профилю.
- [ ] Цифры, гарантии, сроки, сертификаты — только подтверждённые (копии документов у нас).
- [ ] Фото: права подтверждены, это работы клиента; сток не выдаётся за его работы.
- [ ] Отзывы — дословно, с источником; без AggregateRating (шаблон не размечает).
- [ ] Privacy/cookie показаны клиенту (юристу) → `privacy.updated` = дата одобрения.
- [ ] Lighthouse mobile ≥ 95 (главная и услуга).
- [ ] Resend: домен клиента подтверждён на поддомене (`send.`), `CONTACT_FROM_EMAIL` на домене клиента; MX/SPF домена не трогали.

## 3. Запуск на домене
**До DNS**
- [ ] DNS-зона выписана целиком (A, CNAME, MX, SPF/TXT, DKIM). MX/SPF/почту не трогать.
- [ ] За сутки TTL `@` и `www` → 300 с; SPF не опирается на `a`.
- [ ] Старые URL (Internet Archive CDX) → редиректы 308 в `vercel.json`.

**Переключение**
- [ ] Домен в проекте Vercel, `www` → 308 на основной; A/CNAME по подсказке Vercel; старый хостинг не отключать.
- [ ] `client.json`: `facts.siteUrl` = домен, `launched: true` → коммит. Сборка сама упадёт, если не хватает юр. данных или остался `[ЗАПОЛНИТЬ]`.
- [ ] На домене: нет `noindex`, canonical/og:url на домен, JSON-LD без заглушек, `sitemap.xml` и `robots.txt` открыты; на `*.vercel.app` — по-прежнему `noindex`.

**Сразу после**
- [ ] Search Console (Domain через TXT) → sitemap → индексация главной.
- [ ] GA4 (если есть: ID в переменной, хранение 14 мес.) → события в Realtime.
- [ ] Bing Webmaster (импорт из Search Console) + sitemap.
- [ ] Google Бизнес-профиль: сайт, NAP и часы = сайту; услуги, фото, логотип.
- [ ] Каталоги: одинаковые название/адрес/телефон/часы/сайт.
- [ ] Тестовая заявка на домене → письмо/Telegram (+ CRM) → удалить.
