## Главное правило
Всё про клиента — **только в `client.json`** (схема `client.schema.json`). `src/data/*` и `src/content/*` генерируются из него при каждой сборке (`prebuild`): ручные правки там пропадут.

- Правка → `npm run apply-client` (проверка + отчёт «чего не хватает») → `npm run build` → навык `visual-check` → коммит.
- Неизвестный факт = `null` или поля нет. Не выдумывать, не писать `[ЗАПОЛНИТЬ]`. Источник каждого факта — в `sources`.
- Фото — файлом в `src/assets/images/client/`, в данных — путь `client/<файл>`.
- `demo: true`, пока факты не подтверждены клиентом; `launched: true` — только на домене (строгие проверки: юр. название, BTW, почта, домен, дата privacy).
