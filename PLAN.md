# План: стартовый шаблон сайта ISV Labs

Итог: репозиторий-заготовка, из которой новый сайт местного бизнеса собирается заполнением файлов данных; ферма агентов умеет делать это сама и выдавать превью-ссылку.

## Этап 1 — Каркас из Bilto (сессия 1)
- Скопировать архитектуру Bilto без клиентского контента: Astro 7, Tailwind v4, `BaseLayout`, `SEO`, `CookieBanner`, секции (Hero, Diensten, Werkwijze, Waarom, Realisaties, Reviews, Faq, OfferteCta, Header/Footer/MobileBar).
- Единый файл фактов `src/data/site-facts.json` (по образцу INGBELG): название, юр. данные, контакты, часы, город/регион, цифры, `launched`, `siteUrl`, языки.
- Токены темы в одном месте (`@theme` в `global.css`): 2–3 цвета, 2 шрифта (`@fontsource`), радиусы. Смена бренда = правка токенов.
- Секции включаются/выключаются и сортируются в данных (`src/data/sections.json`), без правки разметки.
- Content Collections: `services/`, `regions/`, `gallery/`, `reviews/` — JSON на элемент.
- Заглушки `[ЗАПОЛНИТЬ]`, плейсхолдер-картинки.
- `npm run build` проходит, Lighthouse mobile ≥ 95 на заглушках.

## Этап 2 — Форма, юридическое, SEO (сессия 2)
- `/api/contact`: валидация, honeypot, rate limit → письмо (Resend) + Telegram (`notify-telegram.ts`) + опционально CRM; ошибки уведомлений не ломают ответ.
- Privacy/cookie-политика и условия — шаблоны с подстановкой фактов (показать юристу перед первым реальным запуском).
- schema.org (LocalBusiness/HomeAndConstructionBusiness, FAQPage, BreadcrumbList), sitemap с `lastmod`, robots, canonical/OG от `launched`; `X-Robots-Tag: noindex` на превью.
- Многоязычность: `nl` основной, переключатель, тексты в данных по языкам.
- `visual-check` из A&T: все страницы × 4 ширины, отчёт.

## Этап 3 — «Новый клиент одной командой» (сессия 3)
- Схема данных клиента `client.schema.json` (+ пример `examples/demo-dakwerker.json`): всё, что нужно для сайта, в одном файле.
- Скрипт `npm run apply-client <файл>`: раскладывает данные по `site-facts.json`, коллекциям, токенам; валидирует; пишет список недостающих фактов (`[ЗАПОЛНИТЬ]`).
- Скрипт `npm run new-site <slug>`: копия шаблона в новый репозиторий GitHub + проект Vercel (превью, `noindex`).
- Чек-лист сдачи по `websites/launch-checklist.md`.

## Этап 4 — Подключение к ферме агентов
- Роль/навык для фермы: «Демо-сайт за 15 минут» — Офис-менеджер/Продажи собирают факты (сайт клиента, Google-профиль, текст владельца) → `client.json` → Разработчик: `apply-client` → push → превью → ревью Тимлида → ссылка владельцу.
- Ограничения сервера фермы (1 ГБ, без `npm install`/сборки) — сборку делает Vercel; агент только правит данные.
- Затем — «машина поиска клиентов» (поиск бизнесов со слабыми сайтами → аудит → демо → черновик письма; отправляет владелец).

## Решения владельца (2026-10-12)
- **Дизайн: 2–3 варианта стиля** (например, строгий / тёплый / современный). Стиль выбирается одной строкой в данных клиента (`style: "strict" | "warm" | "modern"`); вариант = набор токенов (цвета, шрифты, радиусы, плотность) + при необходимости вариант раскладки секции (Hero и т.п.), без копий компонентов.
- **Ниша — задаёт владелец для каждого клиента.** Шаблон не привязан ни к одной нише: услуги, иконки, тексты, FAQ приходят из данных клиента; набор универсальных иконок + возможность своей иконки на услугу. Готовых «нишевых» текстов не делаем.
- **Языки — задаёт владелец для каждого клиента.** Список языков в данных (`languages: ["nl"]`, `["nl","fr"]`, …), первый — основной; переключатель и hreflang появляются только при 2+ языках.
